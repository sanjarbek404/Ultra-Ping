# Ultra Ping - Zamonaviy Ping Pong O'yini

Zamonaviy **Geometric Balance** dizayn uslubiga ega, juda tez va silliq ishlaydigan HTML5 Canvas va React asosida yaratilgan Ping Pong o'yini.

## 🎮 O'yin haqida

Klassik Ping Pong o'yinining qayta ishlangan, kiberpank va neon detallariga boy zamonaviy ko'rinishi. O'yin 60+ FPS (maksimal ekranning kadrlar tezligida) ishlashiga mo'ljallangan bo'lib, zarrachalar (particles) va ekran tebranishi (screen shake) kabi nozik "Game Feel" effektlarini o'z ichiga oladi.

### Asosiy xususiyatlar:
- **Yuqori unumdorlik**: O'yin tsikli (Game Loop) React re-renderlarisiz to'g'ridan-to'g'ri `requestAnimationFrame` va HTML5 Canvas yordamida ishlaydi.
- **Sun'iy Ong (AI)**: Sizga qarshi avtomatik harakatlanadigan raqib.
- **Geometric Balance dizayni**: To'r qafasli (grid) fon, o'tkir burchakli chiziqlar, havo rang (Cyan) va qizg'ish-pushti (Rose) ranglar uyg'unligi.
- **Zarrachalar tizimi**: To'p urilganda yoki ochko olinganda portlash effektlari.

## ⌨️ Boshqaruv

Siz doim **chap** tarafdagi raketkani boshqarasiz:
- Tepaga harakatlanish: `W` yoki `Yuqoriga (Arrow Up)` tugmasi
- Pastga harakatlanish: `S` yoki `Pastga (Arrow Down)` tugmasi

**Maqsad**: Birinchi bo'lib 11 ochko yig'ish.
